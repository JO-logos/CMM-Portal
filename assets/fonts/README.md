# Login-page font

`dm-sans-variable.ttf` is the locally hosted DM Sans variable font used only by the login page clock and date. It comes from the official Google Fonts repository and supports the 100–1000 weight range.

The font is licensed under the SIL Open Font License. Keep `OFL-DM-Sans.txt` with the font when the prototype is handed off or moved into an Odoo custom module.
